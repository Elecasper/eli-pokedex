本页面的内容含有大量的剧透。
观看剧透内容后可能会减少在实际观赏或游玩时的兴致，请确定自己是否要浏览。

此页是关于《黑２／白２》的剧情流程，斜体的流程为支线剧情，不是必须进行的流程。

《黑２》的剧情可能与《白２》有部分不同，剧情不同之处会以B2（《黑２》）或W2（《白２》）注明。

序盘

  • 选择是否以全假名或汉字显示日语（日本版）。
  • 桧扇市
    • 选择主角的性别和姓名。
    • 前往西北边的高台，向白露领取最初拿到的宝可梦和宝可梦图鉴。之后与阿修对战。
    • 对战后与白露一同前往宝可梦中心回复宝可梦。收到10个精灵球。
    • 离开宝可梦中心，从妈妈处获得跑步鞋。阿修的妹妹赠送2张城镇地图，让主角将一张交给劲敌。
  • １９号道路
    • 在大门获赠1个伤药。
    • 学习收服宝可梦的方式。
    • 向东边前进，遇见阿戴克。
  • 算木镇
    • 向东北边前进，进入２０号道路。
  • 算木牧场
    • 与阿修对战，然后将城镇地图交给他。
    • 牧场的所有者夫妇出现，帮助他们寻找丢失的哈约克。如果需要回复宝可梦，可以和牧场主的妻子对话。
    • 在牧场北边的森林中遇到等离子队手下，获得招式学习器２１（迁怒）并找到哈约克，没有对战。
  • 算木镇
    • 在阿戴克的家与阿戴克的弟子二连战。每结束一场，宝可梦都会回复状态。
    • 离开阿戴克的家后，获赠奖牌盒。
    • 返回桧扇市。
  • 桧扇市
    • 桧扇道馆（在训练家学校中）
      • 与道馆的2人对战后，和道馆馆主黑连对战。（获胜后获赠招式学习器８３（自我激励）和基础徽章。）
    • 离开道馆后，白露赠送招式学习器２７（报恩）和Ｃ装置。
  • 算木镇
    • 被白露叫住，宝可梦图鉴功能增加栖息地列表。
  • ２０号道路
    • 黑连出现，说明深色草丛并赠送3个桃桃果。
    • 向东边前进，进入立涌市。
  • 立涌市
    • 进入后妈妈会用即时通讯器打电话。
    • 在宝可梦中心门口遇见霍米加与霍米加的爸爸在争吵。
    • 立涌道馆
      • 与道馆的2人对战后，和道馆馆主霍米加对战。（获胜后获赠招式学习器０９（毒液冲击）和毒烟徽章。）
  • 宝可梦好莱坞
    • 欣赏霍米加的爸爸的电影，然后与拍摄室旁边的工作人员对话，参加电影的拍摄。
  • 立涌市
    • 向东南边的码头前进，与等离子队手下对战。
    • 获胜后，霍米加赠送秘传学习器０１（居合劈）。追赶逃跑的等离子队手下，前往２０号道路。
  • ２０号道路
    • 与等离子队手下对战。
  • 立涌市
    • 来到东南边的码头，与阿修对话后乘船。
  • 飞云市
    • 向北边前进。与滑稽演员对话，获得自行车。
    • ４号道路附近的建筑物里有人赠送进化奇石（需要见过40种不同的宝可梦）。
    • 向西边前进，来到飞云道馆前。与道馆向导对话后，跟着艾莉丝来到东南边。
  • 飞云下水道
    • 与阿修一起向西北边前进。和阿修组队与等离子队手下进行多人对战。
  • 飞云市
    • 飞云道馆
      • 与道馆馆主亚堤对战。（获胜后获得招式学习器７６（虫之抵抗）和甲虫徽章。）
    • 向４号道路前进，在广场遇见阿克罗玛，与他约战。

中盘

  • ４号道路
    • 在大门里被白露叫住，获赠探宝器。
    • 与阿克罗玛对战。胜利后获赠攻击增强剂。
  • 向北边前进，穿过汇合大道。
  • 雷文市
    • 前往东南边的云霄飞车。至少与2个训练家对战。然后与终点的女训练家对话。
    • 前往东边的雷文道馆。与3位训练家对战后与道馆馆主小菊儿对战。（获胜后获得招式学习器７２（伏特替换）和伏特徽章。）
    • 前往西北边，与等离子队手下二连战。
  • ５号道路
    • 被白露叫住，获赠秘传学习器０２（飞翔）。听取隐藏洞穴的说明。
    • 与摩托手查尔斯进行轮盘对战B2或三打对战W2
  • 向西边前进，通过帆巴吊桥。
  • 帆巴市
    • 等离子队手下与原等离子队手下争执。没有对战。
    • 北边的等离子队之屋前与宝可梦训练家罗德对战。
    • 前往帆巴道馆，与道馆馆主菊老大对战。（获胜后获赠招式学习器７８（重踏）和震动徽章。）
    • 跟随菊老大和阿修前往南边的PWT。
  • PWT
    • 参加帆巴锦标赛。打败阿修、黑连和阿克罗玛获得优胜。
    • 前往南边的船。
  • 等离子驱逐舰
    • 二连战。随后和黑连、阿修组队对战。之后被黑暗三人组扔下船。
  • ６号道路
    • 黑连赠送秘传学习器０３（冲浪）。
    • 向西北边前进。
      • 遇见勾帕路翁。没有对战。
  • 穿过电气石洞穴
  • 吹寄市
    • 前往吹寄道馆，与道馆馆主风露对战。（获胜后获得招式学习器６２（杂技）和喷射徽章。）
    • 向北前往７号道路。
  • ７号道路
    • 向北前往天堂之塔。
  • 天堂之塔
    • 在１Ｆ遇见红豆杉博士。
    • 返回吹寄市。
  • 吹寄市
    • 在货运中心搭乘飞机。
  • 到达山路镇。向东前进。
  • 在反转山遇到白露，组队。穿过反转山。
  • 涟漪镇
    • 在北边出口与阿修对战。向北边前进，进入１３号道路。
  • １３号道路与勾帕路翁再会，可以对战收服。
  • 笼目镇
    • 听取红豆杉博士和白露说明古老的故事。
    • 前往１２号道路，在笼目镇门口被阿修叫住。等离子队维奥出现，与阿修组队和他进行双人对战。
  • 穿过１２号道路和村庄桥。
  • １１号道路与毕力吉翁相遇，可以对战收服。

终盘

  • 双龙市
    • 前往双龙道馆，与道馆馆主夏卡对战。（获胜后获得招式学习器８２（龙尾）和传说徽章。）
    • 在夏卡的家听取传说中的龙宝可梦的说明。
    • 离开夏卡的家后，等离子驱逐舰袭击双龙市。
    • 打倒3名等离子队手下，在双龙道馆门口与维奥对战，对战结束后夏卡会帮忙回复队内的宝可梦状态。
    • 在东边出口与黑暗三人组的一人对战。
    • 前往涟漪镇。
  • 涟漪镇
    • 来到海洋隧道入口附近时，收到即时通讯器信息。阿修通知海洋隧道开放。
    • 穿过海洋隧道。
  • 青海波市
    • 向北前进，遇见西子伊。
    • 前往青海波道馆，与道馆馆主西子伊对战。（获胜后获得招式学习器５５（热水）和海浪徽章。）
    • 前往２２号道路。
  • ２２号道路
    • 在代拉基翁附近，遇到阿克罗玛。从阿克罗玛处获赠阿克罗玛机器。
    • 返回青海波市，向南边前进。
  • 穿过２１号水路
  • 海边洞穴
    • 对堵住东侧出口的岩殿居蟹使用阿克罗玛机器。对战。
    • 离开海边洞穴。
  • ２１号水路
    • 向东前进，乘上等离子驱逐舰。
  • 等离子驱逐舰
    • 进入北边的船舱，踩下4个传送点解除封锁机关。B2
      • 机关在左上房间，右中房间，左下房间，右下房间。B2
    • 在北边的房间和阿修组队与等离子队手下进行多人对战后，进入南边的船舱，与多名等离子队手下对战，得到密码并获得等离子卡，解除机关。W2
      • 等离子团的密码一共有12个，游戏里会随机出现一个。
        • 莱希拉姆、捷克罗姆、0000、1101、2202、3303、4404、5505、6606、7707、8808、9909。W2
    • 解除机关后，进入最深处。和阿修组队与维奥以及等离子队手下进行多人对战。
    • 对战结束后，被黑暗三人组扔下船。
    • 前往巨人洞窟。
  • ２２号道路与代拉基翁相遇，可以对战收服。
  • 巨人洞窟
    • 进入中央的空地，发现罗德与原等离子队正在和维奥与新等离子队对峙。加入对战，击败等离子队手下。
    • 进入停靠在中央空地冰面中的等离子驱逐舰。
  • 等离子驱逐舰
    • 进入北边的船舱，与多名等离子队队员对战，得到密码并获得等离子卡，解除机关。B2
      • 等离子团的密码一共有12个，游戏里会随机出现一个。
        • 捷克罗姆、莱希拉姆、0000、1101、2202、3303、4404、5505、6606、7707、8808、9909。B2
    • 进入南边的船舱，踩下4个传送点解除封锁机关。W2
      • 机关在十二格（也就是从主角来的左上方平台往地板看）中的第一格，第四格，第六格和第七格。W2
    • 进入屏障后面，与等离子队维奥对战。
    • 进入船头，与阿克罗玛对战。
    • 进入船尾，遇见魁奇思。与黑暗三人组对战。
    • 从船尾离开等离子驱逐舰，向北进入巨人洞窟深处。
  • 巨人洞窟
    • 北边洞窟里与等级55的暗黑酋雷姆B2/焰白酋雷姆W2对战。不可以收服。
    • 与魁奇思对战。期间不能使用道具，但中间会有宝可梦恢复。
  • 穿过２３号道路
  • 冠军之路
    • 入口处Ｎ赠送秘传学习器０５（攀瀑）。
    • 向北边前进，穿过冠军之路。
    • 在最后的洞窟里与阿修对战，获胜后获得招式学习器２４（十万伏特）。
  • 宝可梦联盟
    • 击败四天王婉龙、越橘、嘉德丽雅、连武。
    • 击败冠军艾莉丝。进入殿堂。观看结局画面。

登入名人堂后

登入名人堂后的主要剧情没有严格的先后顺序。

  • 桧扇市
    • 红豆杉博士的爸爸来访。宝可梦图鉴升级成全国版。妈妈赠送活力块。
  • 心之空洞
    • 解放传说中的湖宝可梦。
  • 天堂之塔
    • 在解放传说中的湖宝可梦后，到顶层与艾姆利多对战。可收服。
  • 七宝市
    • 在解放传说中的湖宝可梦后，在博物馆前与由克希对战。可收服。
  • ２３号道路
    • 在解放传说中的湖宝可梦后，来到一处高台与亚克诺姆对战。可收服。
  • 冠军之路
    • 跟着索罗亚克。
    • 被索罗亚克指引至Ｎ的城堡。
  • Ｎ的城堡
    • 与Ｎ对战。胜利后Ｎ将他的龙变为黑暗石B2或光明石W2并赠送给主角。由于有漏洞存在，日版中如果在此战中失败或对战前离开Ｎ的城堡，此段剧情和接下来的剧情将无法再次触发。
  • 龙螺旋之塔
    • 将黑暗石B2或光明石W2复活为捷克罗姆B2或莱希拉姆W2并对战。可收服。
  • 巨人洞窟
    • 与酋雷姆对战。可收服。
    • 对战结束后获得基因之楔
  • 雪花市
    • 每个季节可与黑暗三人组对战一次。
  • 涟漪镇
    • 与阿修对战，胜利后获得秘传学习器０６（潜水）。
  • 帆巴市
    • 每天可与阿修对战一次。
  • Ｐ２实验室-等离子驱逐舰
    • 每天可与阿克罗玛对战一次。
  • 矢车森林
    • 经过天箭桥，与黑连组队，遇见阿苏拉。
  • 三曜市
    • 经过３号道路，来到三曜市。在三曜餐厅，可与天桐、伯特、寇恩其中一位组队跟另两位对战。
  • 梦的遗址
    • 在经过追逐后，拉帝欧斯B2或拉帝亚斯W2对战。可收服。
  • 鹿子镇
    • 经过２号道路、唐草镇和１号道路，若遇见合众图鉴中除了比克提尼、凯路迪欧、美洛耶塔、盖诺赛克特以外的全部宝可梦后获赠许可证。
    • 遇见《黑／白》版主角的妈妈，得知前一代的主角仍然在寻找N，在卧室中可以找到王者之证。
    • 在红豆杉博士的爸爸处获得厉害钓竿。
  • 算木镇
    • 在阿戴克家遇到蕃石郎，前往黑色市B2或白森林W2。
  • 黑色市B2或白森林W2
    • 两地可以进入，在遇到蕃石郎后可进入黑色摩天楼或白色树洞挑战。
  • １８号道路
    • 可以遇到吉宪，且在高台上拾取火山镇石。
  • 反转山
    • 在地下一层使用火山镇石遇见席多蓝恩，与其对战，可收服。
  • 奇幻桥
    • 若在陌生人之家得到新月之羽，则可以遇见克雷色利亚，与其对战，可收服。
  • 罗斯山
    • 在罗斯山内可以触发与传说的巨人的剧情。()
    • 当队伍中同时有雷吉洛克、雷吉艾斯、雷吉斯奇鲁时，则可以遇见雷吉奇卡斯，与其对战，可收服。
  • 宝可梦联盟
    • 可与四天王和冠军重新对战。
