攻略大全 / 究极之日 / 究极之月

终局

第 3 节 · 剧情流程

以太乐园

  • 以太乐园
    • 在一楼和以太分部长扎奥博展开宝可梦对战。
    • 在地下二楼和以太基金会职员展开宝可梦对战。
    • 在地下二楼和哈乌联手和以太基金会职员展开多人对战。
    • 调查秘密实验室Ｂ的电脑。
    • 在一楼和哈乌联手和以太基金会职员展开多人对战。对战结束后，碧珂出现并回复同行宝可梦的状态。
    • 在一楼和格拉吉欧联手和以太基金会职员展开多人对战。
    • 在一楼和哈乌联手和以太分部长扎奥博和以太基金会职员展开多人对战。
    • （上述的多人对战中，每场多人对战结束后，同行宝可梦都会自动回复状态。）
    • 前进的途中，和骷髅队手下们展开宝可梦对战。
    • 和古兹马再次展开宝可梦对战。
    • 前往露莎米奈的宅第，遇到达尔斯和阿玛茉或米翎和西奥尼拉。和究极调查队的达尔斯或米翎展开宝可梦对战。
    • 进入深处的收藏室。露莎米奈承认她是格拉吉欧和莉莉艾的母亲。
    • 和以太基金会理事长露莎米奈展开宝可梦对战，无论胜负都能继续剧情。对战开始前和结束后，同行宝可梦的状态会自动回复。
    • 露莎米奈和古兹马利用小星云科斯莫古力量打开并进入了究极之洞，科斯莫古进化成了科斯莫姆。
    • 次日，离开露莎米奈的宅第。
    • 从格拉吉欧处取得大师球。
    • 前往地下一楼码头处和格拉吉欧对话后前往波尼岛。

波尼岛

  • 海洋居民之村
    • 遇见队长茉莉。
    • 可从船上商店的女性处取得化石翼龙。
    • 可从船上商店的老板处取得熔岩增幅器和电力增幅器。
    • 同行宝可梦中有阿罗拉样子的雷丘时在民家内的女性处可取得阿罗雷Ｚ。
  • 波尼原野
    • 通过波尼原野前往波尼古道。
  • 波尼古道
    • 找到哈普乌。
    • 从哈普乌外婆处取得怪力猛推。
  • 波尼鼓浪岩岸
    • 通过波尼鼓浪岩岸前往彼岸遗迹。
  • 彼岸遗迹
    • 见证哈普乌成为岛屿女王。
  • 海洋居民之村
    • 找到茉莉并和她对话。
    • 团长出现。和团长对话后前往椰蛋树岛。
  • 椰蛋树岛
    • 击败或者收服三只椰蛋树上的凯罗斯。
    • 与椰蛋树对话爬上高地。找到太阳之笛/月亮之笛。
    • 笛子拿到之后，下雨停止。
  • 海洋居民之村
    • 前往波尼古道。
  • 波尼古道
    • 打败两名骷髅队手下。第二场对战结束后，莉莉艾会帮同行宝可梦回复状态。
    • 从布尔美丽处取得毒Ｚ。
    • 前往波尼大峡谷。
  • 波尼大峡谷
    • 在波尼大峡谷的树前，遇到哈普乌，随后莉莉艾以及达尔斯和阿玛茉或米翎和西奥尼拉赶来。
    • 和究极调查队的达尔斯或米翎展开宝可梦对战。
    • 在波尼大峡谷入口前，莉莉艾会赠送活力块并帮同行宝可梦回复状态。
    • 前进到有桥的洞窟前，莉莉艾会帮同行宝可梦回复状态。
    • 在考验门前遇到莉莉艾，莉莉艾会帮同行宝可梦回复状态。
    • 打败霸主宝可梦杖尾鳞甲龙后获得龙Ｚ。
    • 出去洞穴后，哈普乌和莉莉艾会前来祝贺通过考验，莉莉艾会帮同行宝可梦回复状态。
  • 日轮祭坛/月轮祭坛
    • 在祭坛，前往莉莉艾另一侧平台的吹奏太阳之笛/月亮之笛。
    • 莉莉艾的小星云科斯莫姆进化成了索尔迦雷欧，与从究极之洞出来的奈克洛兹玛战斗，不敌后者，被吸收合体成为日食奈克洛兹玛。其他的岛屿也出现了究极异兽。
    • 莉莉艾的小星云科斯莫姆进化成了露奈雅拉，与从究极之洞出来的奈克洛兹玛战斗，不敌后者，被吸收合体成为月食奈克洛兹玛。其他的岛屿也出现了究极异兽。
    • 与奈克洛兹玛（黄昏之鬃）/奈克洛兹玛（拂晓之翼）对战，无论胜负都能继续剧情。对战结束后同行宝可梦会自动回复状态。
    • 借助究极调查队的露奈雅拉或者索尔迦雷欧的力量前往其他颜色的时空洞，遇见各种各样的宝可梦和传说的宝可梦。
    • 借助究极调查队的露奈雅拉或者索尔迦雷欧的力量前往白色的时空洞。
  • 究极空间：究极大都会
    • 在究极大都会塔和奈克洛兹玛（究极奈克洛兹玛）再次展开宝可梦对战。对战结束后同行宝可梦会自动回复状态。
    • 在究极调查队处获得毒贝比。
    • 返回日轮祭坛/月轮祭坛。
  • 日轮祭坛/月轮祭坛
    • 究极调查队打算继续留在阿罗拉地区，露莎米奈和莉莉艾回以太乐园照顾小星云，古兹马独自离开。
    • 此后，茉莉到来。邀请主角参加考验。
    • 可以选择是否和茉莉一起返回海洋居民之村。
  • 海洋居民之村（茉莉的考验）
    • 和队长茉莉对话后，考验开始。和队长茉莉展开宝可梦对战。胜利后获得粉红花瓣。
    • 询问在２号道路往３号道路的考验支援者得知，伊利马在好奥乐墓园。
    • 在好奥乐墓园，遇见哈乌。
    • 前往好奥乐墓园和队长伊利马展开宝可梦对战。胜利后获得橙色花瓣。
    • 对战结束后和伊利马对话选择是否到树荫丛林。
    • 前往树荫丛林和队长玛奥展开宝可梦对战。胜利后获得绿色花瓣。一旁的水莲会给主角蓝色花瓣。
    • 前往树荫丛林和队长水莲展开宝可梦对战。胜利后获得蓝色花瓣。一旁的玛奥会给主角绿色花瓣。
    • 对战结束后和玛奥/水莲对话选择是否到维拉火山公园。
    • 前往维拉火山公园和队长卡奇以及登山男展开宝可梦对战。胜利后从卡奇处获得红色花瓣。
    • 对战结束后和卡奇对话选择是否到辉克拉尼天文台。
    • 前往辉克拉尼天文台和队长马玛内展开宝可梦对战，胜利后获得黄色花瓣。
    • 前往辉克拉尼天文台和队长马玛内对话，获得黄色花瓣。
    • 和马玛内对话选择是否到下一个地方。
    • 在以太之家遇到古兹马和哈乌。
    • 前往以太之家和岛屿之王默丹对话，获得紫色花瓣。
    • 前往以太之家和岛屿之王默丹展开宝可梦对战，胜利后获得紫色花瓣。
    • 和默丹对话选择是否到海洋居民之村。
    • 返回海洋居民之村的茉莉宅，和茉莉对话。茉莉将七色花瓣组合成了虹色之花，召唤出了霸主宝可梦蝶结萌虻。
    • 打败霸主宝可梦蝶结萌虻后，从队长茉莉处取得妖精Ｚ。
    • 离开茉莉宅，遇到哈普乌和哈拉。
    • 哈普乌要主角去椰蛋树岛参加大考验。
    • 与团长对话，前往椰蛋树岛。
  • 椰蛋树岛
    • 和岛屿女王哈普乌展开宝可梦对战，获胜后获得地面Ｚ并返回波尼岛。
    • 前往拉纳基拉山。

乌拉乌拉岛

  • 拉纳基拉山
    • 和格拉吉欧再次展开宝可梦对战。
    • 击败格拉吉欧后，被告知莉莉艾在马哈罗山路。
    • 可以前往马哈罗山路收服索尔迦雷欧/露奈雅拉。成功收服后，莉莉艾会赠送索尔迦雷欧Ｚ/露奈雅拉Ｚ 。
    • 可在拉纳基拉山找到冰Ｚ。
    • 于拉纳基拉山捕捉或击败奈克洛兹玛。捕捉成功后获得究极奈克洛Ｚ并遇到阿克罗玛，赠予了奈克洛索尔合体器及奈克洛露奈合体器。
    • 在山顶的联盟前，如果最初选择的宝可梦在队内，则会跳出来一起回忆战斗过程。
    • 在山顶，挑战宝可梦联盟，和四天王展开宝可梦对战。
    • 在冠军房间，坐下冠军宝座。哈乌前来挑战，和哈乌再次展开宝可梦对战。
    • 登入名人堂，成为阿罗拉地区初代冠军。
