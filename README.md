# Eli的宝可梦图鉴

一个简短、免费的中文图鉴：搜宝可梦查捕捉地点，选地点反查有哪些宝可梦。

- 前7世代807种，GBA／NDS／3DS共22个主系列版本。
- 地点、楼层／分区、遭遇方式、等级、时间与剧情条件；能可靠计算的常规遭遇概率。
- 名称／英文／编号／旧译名搜索，属性与登场世代筛选，进化家族、历史种族值与特性。
- 收集记录按游戏版本保存到当前浏览器，可导出、合并导入。没有账号、追踪或云端数据库。
- HTML内嵌全部资料和807张小精灵图，打开后不请求外部数据、脚本或图片。可保存离线使用。

## 重要限制

**没有记录不代表本作无法获得。** 数据可能缺漏，也可能需要进化、交换或活动。ORAS的普通野外资料尤其不完整；其他作品也不保证完整。主系列的地点不是Pokémon GO实时刷新坐标。

常规概率先按互斥条件重建槽位，再合并等价情况。SOS、群聚、涂蜜树、隐藏洞穴、摆件阈值或源表有冲突时，不强行发布百分比。`—` 表示概率待核对，不是0%。

基础资料为默认形态；地点会另注地区形态。进化家族是通用参考，不保证所选作品能直接满足全部条件。旧联机、双插与活动条件也不保证现在仍能满足。

## 维护

纯静态，无付费服务或依赖包。构建与测试只使用Python标准库，应用使用原生HTML/CSS/JavaScript。

```sh
python3 src/build-eli-pokedex-v1.py --cache /tmp/eli-pokedex-source
python3 src/test-eli-pokedex-v1.py
```

构建脚本固定上游提交、检查缓存版本、拒绝覆盖已存在的生成文件。更新时应另存新版本、重新核查地点和条件，再用生成的HTML更新根目录 `index.html`。不要直接把「latest」当成已核对的数据。
